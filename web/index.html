          FIELD GUIDE

          From research packet to review.

          This workbench supports the project's named-ticker forecast contract. It does not conduct research or replace the five specialist functions.

          1. Prepare the record.Use dated public evidence, one exact reference price, and all four horizons. Leave unsupported forecasts incomplete.
          2. Inspect the gaps.Import schema version 1 JSON or start a blank packet. Edit full packet opens the source, scenarios, and method fields.
          3. Record an actual review.Only record a disposition after independent risk review. Editing research inputs resets an existing local review record.
          4. Export the result.JSON preserves the packet. The brief includes validation gaps. Print / PDF includes the chart when its input and review requirements are met.

          Your research stays in your browser. There is no app upload endpoint, analytics, or cloud sync. The host serves app files and may retain request metadata. External source pages have their own privacy practices.

          Never import credentials, wallet information, personal data, or confidential research. This tool cannot place trades, size positions, connect accounts, or authorize external action.
