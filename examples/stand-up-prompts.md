# Example requests

Paste these into Claude, ChatGPT, Grok, Codex, or the desk. They are research-only.

## Named-ticker forecast

```text
Produce a risk-cleared BTC price probability analysis for 12 hours, 24 hours, 3 days, and 7 days from one exact reference price. Treat a bull cycle as a hypothesis. If a horizon cannot be supported, mark it incomplete.
```

## Asset diligence

```text
Underwrite ETH: economic claim, value capture, on-chain evidence, unlocks, and protocol risk. Date every catalyst from an opened canonical page. No allocation.
```

## Opportunity hunt

```text
Hunt current catalysts, listings, unlocks, and dislocations. Emit recommended_state only. Quarantine unknown liquidity. Reject promotion and anonymous claims.
```

## Full market scan

```text
Test the current crypto market regime. Treat a bull cycle as a hypothesis, use current evidence, keep a conflict ledger, and send every material conclusion through Independent Risk.
```

## Independent risk review

```text
Independent review of the open packet. Do not inherit producer rationale. Return PASS, WARN, FAIL, or UNKNOWN with an assertion ledger.
```
